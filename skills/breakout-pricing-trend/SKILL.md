# 突破、定价与趋势

研究员原则 sheet。通道触发后的归因，不是完整交易系统，也不是个股研报。

主线是方法论，每次覆盖。深度默认不走。

## 原则

**定价默认有效。** 锚没变，价格很少长期停在半空；锚一改，很快贴新上轨。不足反映和错杀不是常态。

**每个判断要有证伪。** 说不出什么会杀死它，判断不成立。

**几何不是理由。** 通道只决定看不看。

**兑现桌不是趋势桌。** a 已经贴上轨后再买，是在赌下一张表。

## 1. 价格事件的捕捉

价格事件的捕捉以通道为主体，触发对变化的归因。e.g. Keltner、Donchian。

主体是价格在挑战已知箱体。命名不了下面的 a/b/c 就空仓。图变漂亮之后再买，是身份漂移。

## 2. 股票价格重估的情形

先问这是谁的桌：

- 这个股票的驱动力，是行业 beta 还是个股 alpha？
- 如果核心驱动力是行业 beta，这个股票是这个板块 / 主题的核心股吗？如果当前股票不是核心，核心股是谁？
- 如果核心驱动力是个股 alpha，它的同行竞争关系、护城河，和竞品替代关系是什么？它的优势稳固吗？

α 的护城河停在驱动力稳不稳。完整竞争格局进深度。

e.g. 交运 β 的核是中远海能 / 招商轮船，或中远海控；东航物流、招商南油是卫星。铜观点用铜或紫金，不用西矿一座矿。

事前分类器不是持续时间。前三天的图长得一样。只问：一次性数字，还是会改下一张表、会不会顺着行业链再改一次。

- **a.** 新消息改变估值数据：往往持续不超过一周，会迅速被机构消化。竞争来源于机构交易员的响应速度，和资金响应速度。
- **b.** 价值重估改变估值锚：变化可以更持久。关键在于一轮重估能否导致下一轮重估，重点是行业的传导链。竞争来源于产业链和估值博弈。a 可以升级成 b；第一次突破仍按 a 看。
- **c.** 情绪共振导致价格脱离估值锚：盈亏同源。表不更新，脱离锚的涨幅就会被偿还。比较危险的区域，竞争是赌性博弈，同时有融资盘踩踏的风险。

## 3. Edge 在哪里？

- **a.** 信息优势：持有私有信息是最根本的优势。量价投资者在这里有后手劣势。默认我们没有私有信息。
- **b.** 扩散优势：要么有更快的响应速度，在新的估值完全兑现之前买入；要么有更广的推理链范围，在其他人意识到关联之前买入。
- **c.** 情绪优势：作用于彩票型股票，或者几年一遇的行业趋势。竞争在于风控策略，正确处理低胜率、高风险、长尾收益，这三者之间的关系。
- **d.** 微观结构优势：一般在冷门股票上更显著。一个参考性的推测是，冷门股扩散更慢，交易量也更难隐藏。这不是铁律。

## 4. 估值的要素

- **a.** 独立估值：套用什么估值模型、在什么外部条件下，我们可以给出多大的估值？乐观、中性、悲观分别有多少，终局估值是多少？这些外部条件有多可靠，有多容易被兑现和证伪？
- **b.** 一致预期：分析师的一致预期在哪里？什么时候给出的？相比我们的独立估值，偏向乐观、中性还是悲观？
- **c.** 价格与估值的消化：当前价格对应独立估值和一致预期，已经消化到哪一档？相对终局估值，还剩多大上行？
- **d.** 消息与估值的预期差：近期消息有没有拉开现实与预期？尤其是估值和价格层面尚未被消化的部分。

独立估值给出我们自己的表。一致预期给出街上的表。上行空间先看街上这张表还剩多少；我们跟街不是同一张表的时候，才谈 extra。终局估值并进街上那张表：它要么是这张表的上轨，要么是我们私下换了一张更矮 / 更高的表。先说是哪一种。

宏观、规模、护城河、技术路线进深度。

e.g. 3 月旭创街上大约 650–820；后来翻倍是 4 月以后换表，不是 3 月没定价完。

## 5. Regime 的因素，对于行业和市场

- **a.** 当前处于价值经济、杠杆经济，还是旁氏经济的阶段？
- **b.** 对于交易者而言，现在是拥挤还是冷门？

## 6. 择时的因素

现在是尚早 / 已经被吃完了，还是已经过度交易了？

## 深度

用于深度研究。默认不作为主线。研报、公告、一致预期或板块叙事已经把它当成这次走势的核心逻辑时，才采用。

- 独立估值的外部条件，是否在挑战宏观、规模、护城河、技术路线等要素？这些条件有多可靠？有多容易被兑现和证伪？
- 如果核心驱动力是个股 alpha：完整的同行竞争关系、护城河、竞品替代关系是什么？优势稳不稳？
- Regime 若要展开：价值经济、杠杆经济、旁氏经济分别怎么落到这只票、这条链？拥挤还是冷门，是这只票、这条链上的，不是「市场热不热」。

e.g. 中芯这次核是成熟制程涨价，不写先进制程国产替代。光模块塌陷若街上在讲终局，才去拆「是上轨还是换表」。
