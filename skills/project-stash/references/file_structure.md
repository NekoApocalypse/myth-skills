## Naming Conventions

All dates use timezone `Asia/Shanghai` (CST).

- **Daily Snapshots:** `{YYYY-MM-DD}_PROJECTS.md` (e.g., `2026-11-03_PROJECTS.md`)
- **Completed Projects:** `{YYYY-MM-DD}_{Project_Name}.md` (spaces replaced with underscores)
