# Convict Conditioning — Training Log

Append new sessions chronologically. Do not rewrite previous entries.

## Entry template

```markdown
### YYYY-MM-DD — Wednesday

- Pushups 5 — 2x10
- Leg Raises 5 — 2x10
- Form/notes:
- Agent assessment:
  - Pushups: not ready / ready to progress
  - Leg Raises: not ready / ready to progress
- Status changes: none
```

```markdown
### YYYY-MM-DD — Friday

- Pullups 2 — 3x10
- Squats 5 — 2x10
- Form/notes:
- Agent assessment:
  - Pullups: not ready / ready to progress
  - Squats: not ready / ready to progress
- Status changes: none
```

## Logging format

Use:

`<Chain> <Step> — <sets>x<reps>`

when every set has the same repetition count.

Examples:

- `Pushups 5 — 2x10`
- `Leg Raises 6 — 2x10`
- `Pullups 2 — 3x20`

If sets differ, record them explicitly:

- `Pushups 5 — 20, 18`
- `Pullups 2 — 30, 27, 24`

If a progression occurs, make it explicit:

- `Status changes: Pushups 5 -> 6 next Wednesday`
